how to add:<br>
<code>
[curse]<br>
SigLevel = Optional TrustAll<br>
Server = https://raw.githubusercontent.com/shroomstech/curse-packages/main/$arch
</code>
run sudo nano /etc/pacman.conf add the code upthere with SigLevel save it and run<br>
sudo pacman -Syu && sudo pacman -Sl curse
